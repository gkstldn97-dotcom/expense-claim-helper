# 개인비용 정산 (영수증 → 엑셀 · PPT)

법인카드 영수증 사진을 모아서 **정산 엑셀(.xlsx)** 과 **영수증 PPT(.pptx)** 를 한 번에 만드는 휴대폰용 웹앱입니다.
아이폰 사파리에서 열고 **홈 화면에 추가**하면 일반 앱처럼 쓸 수 있고, 인터넷이 없어도 열립니다.

- 배포 주소: `https://gkstldn97-dotcom.github.io/expense-claim-helper/`
- 설치: 사파리로 위 주소를 연 뒤 **공유 → 홈 화면에 추가**

## 되는 일

1. **영수증 모으기** — 정산 월을 고르고 영수증 사진을 여러 장 한 번에 고릅니다.
   폰 사진의 회전 정보(EXIF)를 바로잡아 1800px JPEG로 줄여 두기 때문에 대용량 사진도 빠르게 쌓입니다.
2. **내용 채우기** — 영수증마다 날짜 · 금액 · 세부내역 · 계정과목 · 인원 · 결제수단(CC/PC/Cash)을 입력합니다.
   금액은 사진에서 **자동으로 읽어** 채워지고(카드마다 `금액 읽는 중…` → `자동 입력됨`),
   직접 고친 금액은 그대로 둡니다. 영수증에서 날짜가 확인되면 날짜도 함께 채웁니다.
   계정과목을 고르면 영문 계정명과 계정 코드가 함께 채워지고, 순서 바꾸기·삭제가 됩니다.
3. **한 번에 내려받기**
   - `📊 엑셀` — `11월_Expense_Claim.xlsx` (회사 양식을 올려 두면 그 양식으로)
   - `🖼️ PPT` — `11월_영수증_파일.pptx` (16:9, 세로 영수증을 슬라이드 높이에 맞춰 4~5장씩)

## 회사 엑셀 양식 올리기 (선택)

**설정 → 내 회사 엑셀 양식 → 양식 올리기** 에서 회사에서 쓰는 정산 양식 `.xlsx` 를 한 번만 고르면
이 기기에 저장해 두고, 만들 때마다 그 양식의 원본 시트(`CoA`, `Chart of Accounts`, `Index`, `Names` 등)와
서식 · VLOOKUP 수식을 **그대로 둔 채** `Expense Claim` 시트만 채워서 내려줍니다.

- 채우는 곳: 10~59행의 `B`(No) · `C`(Date) · `D`(Description) · `E`(세부내역) · `F`(No Persons) ·
  `G`(Acct Code) · `I`(Type) · `J`(Amount) · `K`(FX Rate) · `L`(Amount KRW 수식), 상단 `L4`(정산일) ·
  `D4`(사원명) · `D5`(부서) · `D6`/`E6`(입금 계좌 · 은행)
- 양식에 이미 적혀 있는 값과 수식은 **덮어쓰지 않습니다.** 사원명·부서처럼 양식이 이미 알고 있는 칸은
  양식의 값(과 `Index` 시트 VLOOKUP)을 그대로 씁니다. 설정에 계좌·은행을 넣어 두면 그 값으로 채웁니다.
- 지난달 데이터가 남아 있으면 10~59행 중 쓰지 않는 행을 비워 합계가 섞이지 않게 합니다.
- 양식을 올리지 않아도 앱에 들어 있는 기본 양식(같은 열 구조)으로 만듭니다.

## 개인정보

- 입력한 값(회사명·사원명·부서·계좌·은행)과 올린 양식은 **그 기기의 브라우저 저장소(localStorage)** 에만,
  영수증 사진은 **IndexedDB** 에만 들어갑니다. 서버로 보내지 않고, 이 저장소에도 개인정보가 들어 있지 않습니다.
- 금액 인식(OCR)도 휴대폰 안에서만 돌아갑니다. 사진은 어디로도 전송되지 않습니다. 인식에 쓰는 엔진·언어
  데이터는 `vendor/tesseract/` 에 함께 배포되며(`NOTICE.md` 참고), 처음 한 번만 내려받습니다.
  인식이 실패하거나 인터넷이 없어도 금액을 직접 넣고 엑셀·PPT를 만드는 데는 문제가 없습니다.
- 만든 파일은 브라우저에서 바로 만들어 휴대폰으로 내려받습니다. (내려받기가 막히면 공유 시트로 저장)
- 휴대폰을 바꾸거나 브라우저 데이터를 지우면 함께 사라집니다. 필요한 달은 파일로 내려받아 두세요.

## 파일 구성

```
index.html            화면
styles.css            스타일
app.js                목록·편집·저장(IndexedDB)·내보내기
ocr.js                영수증 금액·날짜 자동 인식 (파싱 + 브라우저 OCR 호출)
xlsx.js               .xlsx 채우기 (OOXML 직접 수정, 내장 양식·내 양식 공통)
pptx.js               .pptx 생성 (16:9, 이미지 가로 배치)
vendor/jszip.min.js   zip 읽기/쓰기 (로컬 파일, CDN 사용 안 함)
vendor/tesseract/     OCR 엔진·한국어/영어 모델 (Apache-2.0, NOTICE.md)
assets/base.xlsx      기본 정산 양식 (중립값, 수식 포함)
assets/base.pptx      빈 16:9 슬라이드 덱
icons/ · apple-touch-icon.png · manifest.webmanifest · sw.js
```

## 금액 자동 인식이 하는 일

- 사진을 흑백·대비 보정해 읽고, 필요하면 이진화(검정/흰색) 이미지로 한 번 더 읽습니다.
- `합계` · `총액` · `결제금액` · `승인금액` · `판매합계` · `합 계` 같은 표시를 먼저 찾고,
  사업자번호 · 승인번호 · 카드번호 · 전화번호 · 날짜 · `부가세`/`공급가액` 은 후보에서 뺍니다.
- 합계 표시가 없으면 가장 큰 금액을 넣고 “확인해 주세요”로 알립니다.
- 날짜는 거래일시 등에서 분명히 읽히고 그 정산 월에 속할 때만 채웁니다.
- 인식은 카드 한 장씩 차례로 하고, 90초 넘게 안 쓰면 엔진을 내려 메모리를 비웁니다.

## 고칠 때

```bash
python3 builds/expense-claim-helper/make_assets.py   # 기본 양식·아이콘 재생성
```
서비스워커 캐시는 `sw.js` 의 `CACHE = 'expense-claim-v2'` 값을 올리면 교체됩니다.
